# Bedienung

Alles funktioniert wie in Contao — nur die Optik ist anders.

| Bereich | Was man sieht | Bedienung |
|---|---|---|
| Hell / dunkel | Violett (hell) oder Neongrün (dunkel) | Profil-Menü oben rechts → „Dunkles Design" / „Helles Design". Ohne Auswahl folgt das Backend der Einstellung des Computers. |
| Kopfzeile | NEOcms-Logo, Knopf ☰ links | ☰ klappt die Seitenleiste zu einer Icon-Leiste ein; der Browser merkt sich das. Auf Tablet und Handy gilt Contaos eigenes Menü. |
| Seitenleiste | Bereiche („Inhalte", „Layout" …) mit Pfeil | Klick auf den Bereichskopf klappt auf/zu; Contao merkt sich das pro Benutzer. In der Icon-Leiste steht der Modulname im Tooltip. |
| Inhalt | Card auf grauer Fläche, Werkzeugleiste mit Icon + Text | Contao-Funktionen unverändert („Neu", „Alle öffnen", „Mehrere bearbeiten" …). |
| Felder | 40 px hoch, Linie unten wird im Fokus zur Akzentfarbe | Unverändert. Ja/Nein-Felder sind Schalter (Leertaste schaltet). Häkchen zur Auswahl in Listen bleiben Häkchen. |
| Auswahllisten | Liste mit feiner Linie, Häkchen am gewählten Eintrag | Unverändert, lange Listen mit Suchfeld. |
| Meldungen | Fehler/Erfolg/Hinweis in NEO-Farben mit Icon | Unverändert. |
| „Zum Frontend", „Vorschau" | Öffnen die Website auf der Hauptdomain | Siehe [installation.md](installation.md). |
